# Batter Bliss by Khadi

A professional website for Batter Bliss by Khadi, a local bakery specializing in fresh, delicious baked goods.

## Project Overview

This is a responsive web application built to showcase Batter Bliss by Khadi's premium bakery products and services. The website features a clean, modern design that highlights the business's offerings and makes it easy for customers to explore their menu of treats.

## Features

- **Responsive Design**: Fully responsive layout that works seamlessly on desktop, tablet, and mobile devices
- **Product Gallery**: Beautiful showcase of bakery items including:
  - Brownies
  - Cakes
  - Cinnamon Rolls
  - Cookies
  - Donuts
  - Pizza
- **Professional Branding**: Custom logo and cohesive brand identity throughout
- **Mobile-Optimized**: Optimized performance and usability for all screen sizes
